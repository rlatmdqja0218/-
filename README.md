# G-CODE TOOL

웹 브라우저 기반의 3D 프린팅 툴패스 시각화 및 사용자 정의 G-code 생성기입니다.

이 프로젝트는 슬라이서의 기본 채움 패턴을 넘어, 디자이너가 직접 제어한 2D 궤적을 레이어 단위 G-code로 변환하기 위한 개인 작업용 도구로 시작했습니다. 리빙 오브제와 구조적 패턴 연구를 위해 직조형 선 구조, 미세 메시, 기하학적 격자를 빠르게 실험할 수 있도록 설계했습니다.

## 실행

빌드 과정이나 외부 의존성이 없습니다.

1. `index.html`을 브라우저에서 엽니다.
2. 패턴, 밀도, 선 간격, 교차 각도, 속도, 압출량을 조정합니다.
3. 캔버스에서 툴패스를 확인합니다.
4. 생성된 G-code를 복사하거나 `.gcode` 파일로 다운로드합니다.

## 첫 버전 기능

- 실시간 2D 툴패스 캔버스 시각화
- 풀스크린 인트로 화면과 생성형 라인 애니메이션
- 격자, 직조, 메시 패턴 프리셋
- 밀도, 간격, 교차 각도, 이동 속도, 노즐 속도, 압출 배율 제어
- PLA, PETG, ABS, TPU, Silk PLA, Carbon PLA 필라멘트 프리셋
- 리트랙션 길이와 리트랙션 속도 제어
- 총 출력 높이와 레이어 높이/레이어 수 자동 연동
- 레이어 높이와 레이어 수 기반의 표준 G-code 생성
- 레이어별 압출 원점 초기화와 이동 전후 리트랙션 코드 생성
- Minimal Safe Start / End 및 Bambu 레이어 삽입용 프리셋
- GitHub Pages에 바로 배포 가능한 순수 HTML/CSS/JavaScript 구조

## 주의

생성된 G-code는 연구와 프로토타이핑을 위한 출발점입니다. 실제 출력 전에는 사용하는 프린터, 필라멘트, 베드 크기, 온도, 좌표계, 압출량을 반드시 확인하고, 먼저 낮은 높이와 느린 속도로 테스트하세요.
